# Event_Planner

This is a full-stack Java-based Event Planner System built using:
- Java
- Spring Boot
- Hibernate
- REST APIs
- MySQL
- JSP, CSS, JavaScript

#Features
- Add, update, and delete events
- RESTful API integration
- MySQL database for event storage
- Clean frontend UI

#How to Run
1. Clone the repo
2. Import it in STS/Eclipse as a Maven project
3. Set up MySQL and update DB credentials
4. Run the Spring Boot application
